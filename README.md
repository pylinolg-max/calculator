# Калькулятор

Консольное приложение на Python для выполнения базовых арифметических операций.

## Возможности

- Сложение двух чисел.
- Вычитание двух чисел.
- Умножение двух чисел.
- Деление двух чисел.
- Обработка ошибок ввода и деления на ноль.

## Запуск программы

Для работы требуется Python 3.13.

Откройте терминал в каталоге проекта и выполните команду:

`python calculator.py`

После запуска необходимо ввести первое число, выбрать арифметическую операцию и ввести второе число. Программа выведет результат вычисления.

## Тестирование

В проекте реализовано пять модульных тестов с использованием стандартной библиотеки `unittest`.

Для запуска тестов выполните команду:

`python -m unittest discover -v`

Тесты проверяют четыре арифметические операции и обработку деления на ноль.

## CI/CD

Для автоматизации тестирования используется GitHub Actions.

Настройки находятся в файле `.github/workflows/main.yml`.

При отправке изменений в репозиторий автоматически запускаются модульные тесты.

Для Pull Request в ветку `main` настроено автоматическое слияние после успешного прохождения проверок.
